## 運用（2026-11-11 から ID とパスワード）

- **はじめに**：管理ログイン後に `/admin/step` で本部IDを発行 → `/step/` でログインしてパスワードを変える → 「⚙️ 設定」で園長IDを作る → 園長が指導役IDを作る → 園長が「👥 新人」で新人を登録（新人のIDと仮パスワードができる）。
- **IDと仮パスワードの渡し方**：画面の「まとめてコピー」「LINEなどで送る」「印刷して渡す」。仮パスワードはその場で1回だけ表示。
- **パスワードを忘れた**：新人・指導役は園長、園長は本部が「仮パスワード」を出す。本部は `/admin/step`。
- **項目の変更**：「✏️ 項目」（ドラッグ・▲▼・文言修正）。保存すると版が上がる。受け入れ中の新人は「最新の項目にする」を押すまで前の版。
- **個人情報**：名前・入社日・メモ・ログインIDは D1 にだけある。このリポジトリ・Issue・ログに書かない。
