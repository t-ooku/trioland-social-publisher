## 確認したこと（ローカル `wrangler dev` ＋ ローカル D1、Playwright 390px）

- 園長リンクで新人を登録 → 本人用・指導役用のリンクができる
- 本人：「できた」・気分チェック。指導役の「確認」は押せない（API も 403）
- 指導役：1週間の全項目を確認＋面談日 → 段階が「10日」に進む
- 園長：項目をドラッグで1週間→2段階目へ移動 → 保存で版 2。退職を記録 → 本人リンクは 404、「10日で退職」と集計
- 存在しないリンクは 404。全応答に `X-Robots-Tag: noindex`。外部への通信なし。横スクロールなし
- `npm test`（既存の smoke ＋ `test/step.test.mjs`）が通る

## 運用

- **園長リンクをなくした・人が交代した**：管理ログイン後に `/admin/step` → 「園長リンクを発行」。古いリンクはすぐ無効になる。
- **新人・指導役のリンク**：園長リンクの「新人の一覧」で登録。なくしたら新人の画面の「リンクを作り直す」。退職・修了にすると自動で無効。
- **項目の変更**：園長リンクの「項目の編集」（ドラッグ・▲▼・文言修正）。保存すると版が上がる。受け入れ中の新人は「最新の項目にする」を押すまで前の版。
- **個人情報**：名前・入社日・メモは D1 にだけある。このリポジトリ・Issue・ログに書かない。
